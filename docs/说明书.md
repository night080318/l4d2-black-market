# 黑市 Black Market · 使用说明书

> 适合发给朋友看。前面三节讲清楚「为什么要改启动项」「联机能不能用」，后面是开服和玩法。

---

## 一、为什么必须加 `-insecure`

**这不是这个模组的特殊要求，而是 L4D2 对所有「第三方插件」的统一限制。**

### 游戏是怎么加载模组的

L4D2 启动时会扫一遍 `left4dead2\addons\` 目录，看有没有 `.vdf` 插件清单。黑市走的是这条路：

```
addons\metamod.vdf                      ← 游戏看到这个，准备加载插件
addons\metamod\sourcemod.vdf            ← MetaMod 看到这个，加载 SourceMod
addons\sourcemod\plugins\....smx        ← SourceMod 加载黑市
```

链条最后一步是**加载第三方 DLL 代码**。

### 为什么游戏要拦

Valve 的逻辑很简单：**能加载第三方 DLL，就能加载外挂。** 所以只要检测到「要加载插件 DLL」而游戏又不是以 `-insecure` 启动的，就弹窗拒绝：

> 警告：你需要在游戏的启动选项上添加 `-insecure`，才能使用插件。

`-insecure` 的字面意思就是**「本次运行关闭 VAC 反作弊」**。Valve 用这个开关当一道门：你要跑自己的代码，就得先把反作弊让开——风险由你承担，别在受保护的对局里用。

### 所以

| 说法 | 对不对 |
|---|---|
| 「这个模组要改启动项」 | ❌ 所有 SourceMod 插件都要，TF2、CS:S 一样 |
| 「不改也能用」 | ❌ 一个插件都不会加载，`meta` 命令直接不存在 |
| 「改了会封号」 | ❌ `-insecure` 是官方开关，不是破解 |
| 「改了就进不了官服」 | ✅ 对，见下节 |

---

## 二、加了 `-insecure` 之后

| | 状态 |
|---|---|
| 自己开图、朋友进来 | ✅ 正常，插件全部生效 |
| 单机战役 | ✅ 正常 |
| 创意工坊 VPK 模组 | ✅ 正常，不受影响 |
| 官方匹配 / 社区服 | ❌ 进不去（VAC 服务器拒绝 insecure 客户端） |
| 成就、掉宝 | ✅ 不受影响 |

**这是个二选一的开关**，不是永久设置：

- 想玩黑市 → 启动选项写 `-insecure`
- 想打匹配 / 进别人服 → 把启动选项**清空**

改完重启游戏就行，Steam 会记住，不用每次改。

## 三、联机到底能不能用

**能。但「联机」分两种，差别很大。**

### 关键概念：插件跑在服务器上，不在你的游戏里

黑市不是贴图包，它是一段**服务器端代码**。它只在「有一台服务器在跑它」的时候生效。

所以：

| 场景 | 你要加 `-insecure` 吗 | 黑市生效吗 | 为什么 |
|---|---|---|---|
| **你开房，朋友连你** | ✅ 要 | ✅ 生效 | 你的电脑就是服务器 |
| **你自己单机打战役** | ✅ 要 | ✅ 生效 | 同上 |
| 你连朋友的服务器 | ❌ 不用 | ❌ 不生效 | 服务器上没有这个插件 |
| 官方匹配 / 社区服 | ❌ 不用（也进不去） | ❌ 不生效 | 同上 |
| 专用服务器 `srcds` | ❌ 不用 | ✅ 生效 | 服务器端不需要这个开关 |

### 一句话结论

> **你想用黑市，就得自己建房；去别人的服务器，你装什么都没用。**

### 朋友需要准备什么

**什么都不用。** 不用装插件、不用加 `-insecure`、不用改任何设置。

朋友用干净的 L4D2 直接从 Steam 好友列表「加入游戏」，或者控制台 `connect 你的IP:27015` 就进来了，进来就能 `!shop`。

## 四、怎么开一局

> 懒人路线：用一键安装包 `BlackMarket_Installer_v1.4.2.zip`，双击自动找游戏目录，装好 MetaMod + SourceMod + 插件。装完仍然要按下面第 1 步自己加 `-insecure`。

1. 确认启动选项是 `-insecure`（Steam → 右键 L4D2 → 属性 → 通用 → 启动选项）
2. 启动游戏，开控制台（选项 → 键盘/鼠标 → 允许开发者控制台）
3. 输入：
   ```
   map c1m1_hotel
   ```
4. 朋友加入：
   - Steam 好友列表 → 右键你 → **加入游戏**
   - 或控制台 `connect 你的IP:27015`
5. 局域网加 `sv_lan 1`；跨网需要路由器把 **27015 TCP+UDP** 转发到你电脑，并用 `sv_lan 0`

### 验证插件活没活

```
meta list          → 有一行 sourcemod
sm plugins list    → 有一行 Black Market
```

两条都对，聊天框 `!shop` 就有菜单了。

## 五、玩法速查

### 赚补给点

| 行为 | 点 |
|---|---|
| 击杀特感（Smoker/Boomer/Hunter/Spitter/Jockey/Charger） | +3 |
| 击杀 Witch | +5（一击秒杀 +7） |
| 击杀 Tank | +25 |
| 救起倒地队友 | +4 |
| 电击器救活队友 | +6 |
| 给别人治疗 | +4 |
| 通过一章 | 全队 +10 |
| 25 秒内连杀 3/5/8/12 只特感 | 额外 +5/+10/+20/+40 |

### 商店（`!shop` 或按 `B`）

| 分类 | 商品 · 价格 |
|---|---|
| 补给 | 医疗包 8 / 止痛药 4 / 肾上腺素 6 / 电击器 14 |
| 投掷 | 管状炸弹 4 / 燃烧瓶 4 / 胆汁瓶 4 |
| 升级 | 燃烧弹 6 / 高爆弹 6 / 激光 6 |
| 武器（常用） | AK-47 10 / M16 8 / 自动霰弹 9 / 猎枪 8 / 榴弹 16 |
| 更多武器 → 远程 | 冲锋枪 5~6 / 霰弹枪 5~10 / 步枪 8~16 / 狙击枪 8~14 / 榴弹 16 / 手枪 3~6 |
| 更多武器 → 近战 | 撬棍 3 / 棒球棍 3 / 板球棒 3 / 平底锅 3 / 电吉他 4 / 武士刀 6 / 小刀 5 / 砍刀 5 / 高尔夫球杆 3 / 警棍 4 / 消防斧 5 / 电锯 8 |

「更多武器」是分层菜单：远程 / 近战 → 再按枪种分页，每页 6 件，用鼠标点或用数字键都行，返回键逐级退回。

每张图随机 2 件五折，开局 12 秒全服播报。

> **弹药升级要在拿着主武器时买**：燃烧弹 / 高爆弹是直接写进你手上那把枪的（买完立刻生效，不需要使用）；激光瞄准同理。空手或只拿手枪时会提示「需要先拿一把主武器」，不扣点。同一种弹药重复买不会叠加强化，也不会扣点。

### 属性强化（`!attr`）

补给点除了买消耗品，也能买**属性**。每项 3 级，只在**一局战役内**有效：换图、退游戏再进都还在，但**通关或全灭后会清零**，下一局从头再来。

| 属性 | 每级效果 | 1/2/3 级价格 |
|---|---|---|
| 火力强化 | 枪械伤害 +10% | 14 / 28 / 42 |
| 近战强化 | 近战伤害 +18% | 12 / 24 / 36 |
| 投掷强化 | 投掷物初速 +22% | 12 / 24 / 36 |
| 换弹强化 | 换弹时间 -20% | 16 / 32 / 48 |
| 体能强化 | 移动速度 +10% | 18 / 36 / 54 |

点满一项要 72~108 点（按一只特感 +3 算，差不多 24~36 只），五项全满合计 432 点——一局里基本不可能，所以这是「一局选一条路走」的取舍，而不是全都点满。

> **火力 / 近战强化**从 1.4.4 起对**所有感染者**生效：普通僵尸、特感、Tank、Witch 都吃加成（之前只对普通僵尸生效，打特感和 Tank 没反应）。三级分别是 ×1.30 和 ×1.54。
>
> **体能强化**从 1.4.4 起真正生效（之前写的字段 L4D2 引擎不认）。**只加在自己身上**，不会影响队友，也不会影响特感和僵尸的速度。默认三级 +30%。
>
> **换弹强化**从 1.4.3 起真正生效（之前改的值会被引擎覆盖）。三级一共 -60%，AK-47 的换弹从 2.06 秒缩到 0.82 秒，换弹动画也会同步加速；霰弹枪逐发装填同样加快，榴弹发射器再额外快一点。狙击枪的拉栓间隔也会缩短，但**拉栓动作本身不加速**——引擎会重播整段开火动画（多掉一个弹壳），所以动画保持原速。
>
> **投掷强化**在 1.3.2 重写过（改成等到出手瞬间再加速），逻辑上通了，但还没做完整体感实测。

> **补给点默认也一起清零**，让经济循环每局重来。只想清属性、保留点数的话，把 `sm_bm_reset_points` 设成 `0`。

### 提示音（可选，要订阅才响）

买成功「叮」一声，点数不够「咚咚」两声。这是**配套创意工坊物品**，不订阅就完全没有声音，但功能一切正常——只是安静地买东西。

- 订阅：创意工坊搜 **Black Market Sound Pack · 黑市提示音包**（也可以从插件 README 里的链接进）
- **每个想听到声音的人都要自己订阅**，因为声音是在各自的客户端上播的
- 没装插件的服务器里订阅了也不会响，这是设计如此，不是故障
- 服务端开关 `sm_bm_sounds`（默认 1）；播放方式 `sm_bm_sound_mode`（默认 0，唯一实测可用的方式，一般别动）

### 命令

**快捷键：按 `B` 打开商店。** 进服后插件会自动帮你绑定（聊天框提示一次），不用手动设置；不想让它动按键就把 `sm_bm_autobind` 设成 `0`。

| 命令 | 作用 |
|---|---|
| `!shop` / `!bm` | 商店 |
| `B`（快捷键） | 同上，进服自动绑定 |
| `!attr` | 属性强化面板 |
| `!pts` | 看自己的点数和击杀 |
| `!top` | 排行榜 |
| `!cheat` | 作弊：花多少自动补回 9999 点 |
| `!bmadd 500` | 作弊：直接加 500 点 |
| `!bmzero` | 作弊：补给点直接清零 |

## 六、排错

| 现象 | 原因 | 处理 |
|---|---|---|
| 启动弹窗要 `-insecure` | 没加启动选项 | 加上，重启游戏 |
| `meta` 是 Unknown command | MetaMod 没加载 | 同上 |
| `meta list` 有 sourcemod，`sm` 没有 | SourceMod 加载失败 | 看 `addons\sourcemod\logs\errors_*.log` |
| `sm plugins list` 没有 Black Market | 没扫到 | `sm plugins load l4d2_black_market` |
| 有插件但 `!shop` 没反应 | 不在开图的服务器里 | 先 `map c1m1_hotel` |
| 「附加内容」里看不到 | 正常，那菜单只列 `.vpk` | 别在那儿找 |
| 买东西没声音 | 没订阅音效包，或 `sm_bm_sounds 0` | 订阅音效包；`sm_bm_sounds 1`；`!bm_sndtest` 自检 |
| 朋友连不进来 | 端口/防火墙 | 开 27015 TCP+UDP，或先试局域网 |

---

## 七、安全提醒

`-insecure` 状态下 VAC 不工作，所以这个模式里**只装你自己看得懂的插件、只连你信任的服务器**。打完自己那局，把启动选项清空，回到正常模式去打匹配，这样最稳。
